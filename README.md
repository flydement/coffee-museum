# 拾光咖啡博物馆 · Atelier Café Museum (v5.5)

线上体验地址：**https://flydement.github.io/coffee-museum/**

一套代码同时覆盖 **Web / PWA、PC 桌面端（Electron）与移动端 App（Capacitor iOS / Android）** 的精品咖啡风味策展与沉浸式冲煮工坊。

## 核心亮点

1. **全馆速查检索台与直达链接路由（Quick Finder & Deep Linking）**
   - 随时按 **`⌘K` / `Ctrl+K`** 或点击顶栏搜索键，毫秒级检索 **40 款馆藏风味**、器具、产区及馆内博物工具（支持「云南普洱百花蜜」「艺伎/瑰夏」「花魁」「脏咖」等中英文同义词检索），方向键直达展品档案或进入冲煮。
   - 完整 Hash + History 路由同步（`#exhibit/<id>`、`#studio/<id>`、`#atlas/<section>`），支持刷新保活、手机端右滑返回关闭弹窗/回退展厅，以及一键复制展品或冲煮工坊直达分享链接。
2. **风味策展台与情境点单（Flavor Curator）**
   - 首页配备 **5 幅复古手绘常设展无缝循环轮播**（支持触控滑动、键盘焦点与系统减弱动效适配）及**今日馆长精选展签**。
   - 内置 **8 大生活情境一键调味**、四维风味调音台滑块、香气联想标签、高契合展品 6/12 款一键展开、**想喝清单（♥）**与**今日风味抽签盲盒**（含品鉴签文与甜点搭档）。
3. **世界咖啡馆藏展厅与双豆雷达对比（Museum Gallery）**
   - 收录 **40 款代表性世界馆藏风味**（手冲黑咖、意式奶咖、冰爽特调与复古器具四大展区各 10 款，涵盖云南普洱百花蜜处理、哥伦比亚玫瑰谷、埃塞古吉花魁、港式丝袜鸳鸯、阳光青提气泡冷萃、经典浓缩汤力、萨尔瓦多帕卡马拉虹吸等）。
   - 支持按分类、烘焙度光谱、温度、难度、想喝清单与多维风味排序检索；支持任选两款开启**「双展品五维风味雷达重叠对比」**，以及一键复制完整文字配方或直达链接。
4. **沉浸式分步冲煮工坊（Interactive Brewing Studio）**
   - **14 种动态 SVG 萃取器具实时演示**：V60 手冲、Chemex、聪明杯底阀放流、法压壶、爱乐压快萃、虹吸真空壶、土耳其铜壶、越南 Phin 滴漏壶、八角摩卡壶、半自动意式机、奶咖拉花、Dirty 分层、冰滴与鲜果气泡特调杯，液位随倒计时连续变化。
   - **口味定制微调（Taste Customizer）**：动态切换 `馆藏标准` / `更甜润柔和` / `更清爽花果` / `更浓郁醇厚`，自动换算粉量、总液量、分步累计目标与水温。
   - **解放持壶双手体验**：切出展厅查图鉴时**自动保留当前冲煮计时与进度**；提供实时跟随电子秤与注水流速导引（`ml/s`）、**实时已用/总长/剩余时间轴**、**最后 3-2-1 声学倒计时提示**、自动连贯跳步、中文语音播报、切回前台自动续锁屏幕常亮（Wake Lock）、快捷键（`Space` 计时 / `←→` 切步 / `R` 重置 / `M` 静音）与出杯一键风味品鉴短签。
5. **风味博物图鉴与诊断工具箱（World Coffee Atlas）**
   - **世界咖啡种植带交互地图**（15 大产区）、**交互式风味轮 + 手冲/冷萃/意式粉水与咖啡因计算器**、**烘焙光谱与生豆处理法实验室**、**咖啡师翻车诊断室**与 **18 题随机抽题趣味问答**。
6. **馆内声景、日夜灯光、四色明信片与个人馆藏（Archive）**
   - 顶部栏一键切换**全馆速查**、**提示音静音**、零依赖 Web Audio **雨夜吃茶馆白噪音**与**日间暖白 / 深夜吃茶馆暖暗主题**；针对手机端全面重构防横向溢出、顶栏紧凑排版与底部导航安全区适配。
   - 自动生成**个人风味指纹雷达图**（支持统计累计耗豆克数、最常用器具，并一键按历史风味指纹回填策展台）、集成**我的想喝清单**与 **8 枚博物馆策展徽章**；支持冷热饮自动匹配插画与复古印章的 **4 款卡纸主题高清 PNG 明信片**（含「京都蓝染和纸」），以及字段校验的 **JSON 跨端馆藏备份导入/导出**。

## 本地开发与验证

```bash
npm install
npm run dev      # 启动本地开发服务器
npm run lint     # Oxlint 静态代码检查
npm test         # 运行零依赖单元测试与 40 款馆藏数据完整性校验
npm run build    # TypeScript 类型检查 + Vite 生产构建（输出到 dist/）
```

## 多端打包指南

### 1. PC 桌面客户端（Windows / macOS / Linux · Electron）

```bash
npm install -D electron electron-builder
npm run desktop:start   # 构建并以 PC 桌面窗口启动
npm run desktop:build   # 打包生成 macOS (.dmg) / Windows (.exe) / Linux (.AppImage) 安装包
```

### 2. 移动端原生 App（iOS / Android · Capacitor）

```bash
npm install @capacitor/core
npm install -D @capacitor/cli @capacitor/ios @capacitor/android
npx cap add ios
npx cap add android
npm run mobile:sync     # 构建 dist 并同步至原生工程
```
